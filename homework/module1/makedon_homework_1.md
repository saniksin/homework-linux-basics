## Завдання 1. Базові команди

### 1.1 Показати вміст домашнього каталогу

```bash
ls ~
```

або

```bash
ls /home/$USER
```

### 1.2 Перейти у каталог Downloads і показати його вміст

```bash
cd ~/Downloads
ls
```

### 1.3 Створити порожній файл (без `touch`)

```bash
> empty_file.txt
```

Перенаправлення stdout у файл без жодного виводу створює порожній файл. Ще варіант: `: > empty_file.txt` (команда `:` є вбудованою no-op у bash).

### 1.4 Переглянути вміст файлу

```bash
cat empty_file.txt
```

Для великих файлів краще `less empty_file.txt` (посторінковий перегляд із навігацією).

### 1.5 Перейти у домашній каталог абсолютним шляхом

```bash
cd /home/saniksin
```

### 1.6 Перейти у домашній каталог відносним шляхом

Якщо знаходимось у `/home/saniksin/Downloads`:

```bash
cd ..
```

Або з будь-якого підкаталогу домашнього (з більшою глибиною):

```bash
cd ../..
```

**Примітка щодо `cd ~`:**
Команда `cd ~` також перейде у домашній каталог, але строго кажучи це **не відносний шлях**. Тильда (`~`) — це shell-метасимвол, який bash розкриває у абсолютний шлях `/home/saniksin` ще до виконання команди. Перевірити це можна так:

```bash
echo ~
# /home/saniksin
```

Тобто `cd ~` еквівалентно `cd /home/saniksin` — абсолютний шлях.
До відносних шляхів належать виключно ті, що не починаються з `/` і залежать від поточного робочого каталогу: `..`, `../..`, `./subdir`, `subdir/file`.

## Завдання 2. Робота з документацією

Виконані команди:

```bash
man ls
help cd
man cat
man man
cp --help
mv --help
```

### Питання 1. Який ключ `ls` показує приховані файли?

Ключ **`-a`** (або `--all`) — показує всі файли, включно з тими, що починаються з крапки (прихованими):

```bash
ls -a
```

Додатково: `-A` (`--almost-all`) показує приховані файли, але не виводить `.` та `..`.

### Питання 2. Який ключ у `cat` нумерує рядки?

Ключ **`-n`** (`--number`) — нумерує всі рядки виводу:

```bash
cat -n file.txt
```

Споріднений ключ: `-b` (`--number-nonblank`) нумерує тільки непорожні рядки.

### Питання 3. Чим відрізняються `man` і `--help`?

| Критерій | `man` | `--help` |
|---|---|---|
| Джерело | Окремі manual-сторінки з `/usr/share/man/` | Зазвичай вбудований у програму текст |
| Обсяг | Повна документація: опис, приклади, SEE ALSO, BUGS | Короткий огляд синтаксису та опцій |
| Структура | Розділений на секції (NAME, SYNOPSIS, DESCRIPTION, OPTIONS, EXAMPLES…) | Зазвичай простий список опцій |
| Перегляд | Відкривається у pager (`less`) — можна шукати через `/` | Виводиться у stdout, зазвичай 1–2 екрани |
| Приклад | `man ls` | `ls --help` |

Коротко: `man` — повна наукова документація, `--help` — швидка довідка "як викликати".

## Завдання 3. Міні-сценарій

Сценарій із 9 команд, що використовує лише матеріал тем 1–5:

```bash
# 1. Перейти у каталог /tmp
cd /tmp

# 2. Створити там один файл
> my_test_file.txt

# 3. Переглянути список файлів (з деталями та прихованими)
ls -la

# 4. Перейти в інше місце (домашній каталог)
cd ~

# 5. Повернутись назад (до /tmp) через спеціальний параметр cd
cd -

# 5.1 Перевірити, що ми дійсно повернулися
pwd

# 6. Переглянути документацію однієї з команд
man ls

# 6.1 Вийти з man (натиснути q) та повернутися в домашній каталог
cd ~
```

### Пояснення кроків

1. `cd /tmp` — переходимо у тимчасовий каталог, де безпечно створювати тестові файли.
2. `> my_test_file.txt` — створюємо порожній файл через перенаправлення stdout.
3. `ls -la` — бачимо щойно створений файл, а також дозволи, власника, розмір.
4. `cd ~` — переходимо до домашнього каталогу (тильда — shortcut).
5. `cd -` — повертаємось до попереднього каталогу (`/tmp`). Команда `cd` пам'ятає останній каталог у змінній `$OLDPWD`.
6. `pwd` — виводить поточний робочий каталог для перевірки.
7. `cat my_test_file.txt` — перевіряємо вміст (файл порожній, вивід теж буде порожнім).
8. `man ls` — читаємо документацію по `ls`, навігація стрілками та PgUp/PgDn.
9. `cd ~` — після виходу з `man` (клавіша `q`) повертаємось додому.
