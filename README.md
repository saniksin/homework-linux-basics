# Linux Course — Homework

Домашні завдання з курсу Linux / DevOps Basics.

**Автор:** Олександр Македон

## Структура

- `module1/` — Основи Linux і робота в терміналі
- `module2/` — Bash-скриптинг і автоматизація (скрипт бекапу логів)
- `module3/` — Процеси, пріоритети та моніторинг ресурсів
- `module5/` — Мережа та віддалений доступ (SSH, scp, rsync, sftp)
- `module_os_containers/` — ОС і контейнери (контейнер як Linux-процес: PID 1, сигнали, логи)
- `moduleN/` — додаватиметься по мірі проходження курсу

## Формат

Кожне домашнє завдання — окремий `.md` файл у відповідному модулі:
`moduleN/makedon_homework_N.md`
